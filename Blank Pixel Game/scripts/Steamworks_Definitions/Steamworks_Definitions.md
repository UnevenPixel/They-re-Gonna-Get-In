# Steamworks_Definitions

Vendored enum mirrors of the Steamworks C++ SDK's various enums (`ESteamNetConnectionEnd`, `ESteamNetworkingConnectionState`, `EPersonaState`, etc.), for use with the Steamworks GameMaker extension. Comments on individual enum members are Valve's own SDK documentation, preserved as-is for reference when calling Steam API functions -- not project-authored design history, so nothing here has been relocated or trimmed beyond the file header.

## API

- `STEAM_PARTIES_BEACON_LOCATION`, `STEAM_PARTIES_BEACON_LOCATION_DATA`
- `STEAMWORKS_FRIENDS_FLAGS`, `STEAMWORKS_PERSONA_STATE`
- `STEAMWORKS_NET_CONNECTION_STATE`, `STEAMWORKS_NET_SEND_FLAG`, `STEAMWORKS_NET_FAKE_IP_TYPE`, `STEAMWORKS_NET_IDENTITY_TYPE`, `STEAMWORKS_NET_AVAILABILITY`, `STEAMWORKS_NET_CONNECTION_END`
- `STEAMWORKS_BEGIN_AUTH_SESSION_RESULT`, `STEAMWORKS_AUTH_SESSION_RESPONSE`
